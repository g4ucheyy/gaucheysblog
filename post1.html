Whats that?

Chaos Randomizer is a fabric based minecraft java mod featuring randomized modifiers every randomized seconds

First version (Chaos Randomizer 0.1) was released in September 6th

Current version (Chaos Randomizer 0.2) was released in September 13th

Features

Randomized Modifiers (literally the title)

lists:

  • Random explosions
  • Shazam! (Lightning bolt, alot of)
  • Random potion effects with randomized amplifiers
  • Set a fire around you (hot)
  • Delivery 4 ya (Mobs, hostile)
  • Random items (OP sticks)
  • Levitation

To do (In development)

  • TNT rain?

  • I forgot

Requirements

  • A device (I guess?)
  • Minecraft Java 1.21.11 (Fabric)
  • Enable Allow Command so you can deactivate the mod whenever you want

Make sure you download the chaosrandomizer-0.2.jar to play (the others are for devs I guess)

Command

  • /chaos - Shows all available command
  • /chaos give - gives the sticc boi
  • /chaos activate - activate the randomizer
  • /chaos disable - deactivate the randomizer
